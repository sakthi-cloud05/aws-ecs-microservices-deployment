# aws-ecs-microservices-deployment

Containerized Application Deployment using Amazon ECS & AWS Infrastructure

Container Orchestration: Deployed and managed microservices applications on Amazon ECS (Elastic Container Service) utilizing Amazon ECR for image registry storage and lifecycle management.

Cloud Networking & Security: Configured custom AWS VPC architecture featuring public/private subnets, Internet Gateways, NAT Gateways, and granular Security Groups to isolate application workloads.

Traffic Routing & Resilience: Implemented an Application Load Balancer (ALB) with target group health checks and path-based routing to ensure high availability and smooth traffic distribution across container tasks.

CI/CD Integration & Monitoring: Integrated GitHub / Jenkins pipelines for automated container builds and zero-downtime rolling deployments, backed by AWS CloudWatch alarms for continuous log monitoring and metric tracking.
